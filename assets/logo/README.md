# Знак Meshly

Замкнутый круг узлов без центра: связь держится сама, без вышки.

Всё — и SVG, и три десятка PNG — собирается одним скриптом. Руками файлы
не правят.

```bash
python3 tool/generate_icons.py                      # текущие параметры
python3 tool/generate_icons.py --width 1.5 --scale 2.2
```

Параметры: `--width` — толщина перекладин, `--radius` — радиус узла,
`--scale` — размер знака внутри плитки 108×108. Все три в единицах сетки
24×24. Цвета — константы `BRAND` и `INK` в самом скрипте.

## Исходники

- `glyph.svg` — 24×24, `currentColor`, вплотную к краям.
- `adaptive-foreground.svg` — 108×108, передний слой адаптивной иконки
  Android. Знак умещается в безопасную зону, которую не срежет ни одна
  маска. Фон непрозрачный намеренно: по спецификации он задаётся отдельным
  слоем, но часть лаунчеров подставляет собственный вместо объявленного, и
  белый знак на белой подложке исчезает.
- `mark.svg` — 108×108 с фоном, из него растрируются иконки iOS и
  классическая иконка Android.

## Что получается

| Куда | Что |
|---|---|
| `mipmap-*/ic_launcher.png` | классическая иконка Android |
| `mipmap-*/ic_launcher_foreground.png` | передний слой адаптивной |
| `mipmap-*/ic_launcher_monochrome.png` | слой для перекраски под обои (Android 13+) |
| `drawable-*/ic_notification.png` | силуэт в строке состояния |
| `drawable-*/splash_logo.png` | знак на заставке Android |
| `LaunchImage.imageset/*` | знак на экране запуска iOS |
| `AppIcon.appiconset/*` | иконки iOS, без альфа-канала |

## Ловушка с прозрачностью

Единственный доступный отрисовщик SVG на macOS — системный `qlmanage`, и
он **заливает прозрачный фон белым**. На белом такой файл выглядит
правильно, но альфа-канал у него сплошь непрозрачный.

Для иконки приложения это безразлично (фон и так закрашен), а иконку
уведомления Android рисует **по одной лишь альфе, игнорируя цвета** — и
такой файл превращается в сплошной белый прямоугольник в строке
состояния. Ровно это и случилось при первой сборке.

Поэтому силуэты рисуются чёрным по белому, а прозрачность вычисляется из
яркости. **Проверять готовый файл надо по альфе, а не глазами**: белое на
белом на глаз не отличить от прозрачного.

## Осознанно не сделано

- `ic_launcher_round` — нужен лаунчерам Android 7.0–7.1; знак центрирован
  с запасом, автоматическая обрезка под круг его не портит.
- Заставка через SplashScreen API (Android 12+) — система там сама рисует
  первый экран из адаптивной иконки, знак виден и без этого. Своя
  реализация дала бы контроль над фоном ценой новой зависимости.
- Тёмный и тонированный варианты иконки iOS 18 — иконка остаётся синей на
  любой теме.
